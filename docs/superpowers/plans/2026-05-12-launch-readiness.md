## Outbound dependencies (cross-repo — planned separately)

These items live in the user-portal repo and need to be planned/built there. They are NOT this plan's tasks; they appear here so launch coordination tracks them.

| Item | Repo | Why it matters | Impact if missing on launch |
|---|---|---|---|
| Impersonation amber banner | user-portal `apps/web` middleware | Customer sees they're being impersonated | Trust/legal risk; admin can impersonate silently |
| `mv_org_cost_summary` materialized view | user-portal Supabase migrations | Powers `/admin/revenue` cost summary tile | Tile shows `—` instead of cost data |
| Email on ticket reply via Resend | user-portal | Customer gets email when admin replies to ticket | Replies happen silently; customer doesn't know |
| End-user ticket submission form | user-portal `apps/web` | Customers can open tickets | No customer-side ticket creation; only manual seed |
| Scheduled rate-card publish cron | user-portal Supabase Edge Function | Rate cards auto-publish at scheduled time | Scheduled publishes silently miss their window |
| `user_sessions` table | user-portal | Powers suspicious-session detection in `/admin/security` | Security tab shows empty session list |

**Action:** open a separate plan in user-portal repo when ready, or document parking decisions per item.
